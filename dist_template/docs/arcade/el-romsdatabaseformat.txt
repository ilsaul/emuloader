Notes:
 - If both CRC32 and SHA-1/MD5 are empty, it means the file is tagged as "nodump"

 - ROMs/CHDs tagged as baddump have no special treatment when auditing sets. This tag is just for user information

 - The "optional" tag in MAME's -listxml output is ignored when validating games. All game files are required by the frontend

 - The FileID tag is there to separate the files in categories and is required by Emu Loader
   so ROM/CHD files can be properly categorized and to make the validation easier (see File ID Codes section below)

 - The MediaType tag is there to properly separate files (similar to "<rom" and "<disk" tags in -listxml output)
   Required for proper games files validation

 - The IsCRC32Collision tag on each ROM is used to detect multiple ROMs in the same set with the same CRC32 but different SHA-1 checksum

 - The IsParentSetFile tag on each ROM is used on clone sets to show if a ROM is from the parent set or the clone set

 - The <part_name> and <part_title> tags are for software list games only; see game [amerisuc] above from "msx2_flop" software list

 - When a clone game use the CHD file of the parent game, a <parentname> tag is used

 - Daphne is the only system that do not have a ROMs list

 - Tags <region> and <offset> are used in Supermodel 3 Emulator only

 - Only arcade systems and MAME software list games are supported
