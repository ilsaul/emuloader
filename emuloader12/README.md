# EmuLoader Delphi 12/13 conversion

This folder is the working copy used to port the original Delphi 7 project to modern Delphi versions, including Delphi 12 and Delphi 13.

Typical workflow:

1. Open the project in a Windows machine with Delphi 12 or Delphi 13 installed.
2. Run `build.bat` or `build.ps1` from this folder.
3. Fix the next compiler error, one at a time.
4. Rebuild until the project is clean.

The main compatibility topics are:
- custom VCL controls under `lib/delphi7-components`
- `Tnt` Unicode controls
- legacy Delphi 7 startup code and package dependencies
- component registration paths and global search paths

Automation:
- `build.bat` is for Windows/VM usage and auto-detects the newest Delphi install
- `build.ps1` is the PowerShell equivalent
- `build.sh` is for Linux Docker/Wine execution
- `build.log` is generated by the PowerShell runner for unattended builds
